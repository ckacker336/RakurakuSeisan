# 楽楽精算インポート用 CSV自動生成ツール

## 1. プロジェクト概要
経費精算システム「楽楽精算」への交通費入力業務を効率化するための、Node.jsベースのコマンドラインツールです。特定の年月の平日データを自動抽出し、一括インポート可能なCSVファイルを生成します。

## 2. 開発の背景と目的
* 毎月の交通費精算において、平日の往復データを手動で一行ずつ作成・入力する作業が発生していたため
* 技術力向上のため

## 3. ツールの機能詳細

### 交通費CSV自動生成ツール (`csv.js`)
* **平日自動抽出**: 指定された年月の「月曜日〜金曜日」を自動的に判定・抽出する。
* **休暇日の判定**: ツール実行時に「休暇日（祝日含む）」を日単位で入力することで、対象日を動的に除外する。
* **CSV連携**: 楽楽精算のインポート形式に準拠したヘッダー付きCSVを出力し、システムへの直接アップロードが可能となる。

## 4. 今後の課題
* **祝日の自動判定**: どのように実現できるか調査し、手入力なしで祝日を自動的に精算対象から除外する機能の実装。
* **実行時の日付自動取得**: 実行時のシステム日付から現在の年月を自動取得し、ソースコードの書き換えなしで実行可能にする。
